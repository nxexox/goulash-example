Как это работает

Два независимых контура. Поиск отвечает мгновенно по подготовленной базе и никогда не ходит на внешние сайты. Фоновый сборщик находит компании в публичных каталогах, разбирает их сайты и публикует факты с источниками.

Онлайн — поиск

  1. Разбор запроса: товар, город/регион доставки, количество. Словари, без LLM.
  2. Исправление опечаток по словарю проиндексированных терминов (pg_trgm).
  3. Полнотекстовый поиск PostgreSQL по стеммированному тексту, затем совпадения по категории — с пометкой.
  4. Ранжирование: товар → связь с регионом → полнота и коммерческие условия → свежесть.
  5. Мало результатов — запрос уходит в очередь поиска новых источников.

Фон — сбор данных

  1. Адаптер каталога идёт по реальной пагинации и сохраняет checkpoint.
  2. Карточка участника → кандидат. Ключ слияния — домен сайта.
  3. Сайт компании: главная и до 3 страниц «контакты / доставка / о компании».
  4. Правила извлекают телефоны, e-mail, ИНН (с контрольной суммой), сертификаты, MOQ, цены, доставку. Каждый факт хранит фрагмент текста и ссылку.
  5. Очередь в PostgreSQL с lease: повтор с backoff, блокировки → ручная проверка.

Почему так

  • Неизвестное — это «нет данных», а не 0. Цены и MOQ публикуют редко; сервис формирует вопросы для звонка.
  • Офис ≠ доставка. Поставщики с подтверждённой доставкой и с офисом в регионе показываются отдельно от остальных.
  • Категория ≠ товар. Совпадение только по категории помечено: «Сыры» не доказывают наличие моцареллы.
  • Вежливый сбор. robots.txt, одна загрузка на домен, задержка, бюджет запросов, честный User-Agent. Каталоги, запрещающие копирование, не подключены.
  • Расширяемость. Загрузчик — цепочка middleware: прокси-пулы, ротация заголовков, headless-браузер или локальная LLM для сложных фрагментов добавляются без изменения адаптеров.

Ограничения прототипа

  • Каталог выставки — не полный рынок; покрытие растёт с каждым запуском сборщика.
  • Извлечение условий — правила, без ручной проверки; ошибки возможны, поэтому всегда показан исходный фрагмент.
  • Заметки и шорт-лист общие для всех (нет авторизации).
