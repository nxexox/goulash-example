# GOULASH — исследование и PoC

[Исходное тестовое задание (PDF)](assignment.pdf)

Материалы тестового задания: архитектура поиска поставщиков, проверка источников, скрипты обнаружения и парсинга, снимки страниц и результаты экспериментов.

Архитектура: онлайн-поиск по подготовленной базе и независимый фоновый сбор/обновление. Полная схема Mermaid и план находятся в PLAN.md по ссылке ниже.

## Запуск

Python 3.10+; внешние Python-зависимости не нужны. Запускайте команды из этой папки.

Офлайн по сохранённым данным:

```sh
python3 pipeline.py
python3 extract_supplier.py
python3 search_poc.py
```

Сетевые проверки (ограниченная выборка):

```sh
python3 probe.py
python3 discover.py
python3 sample_catalogs.py
python3 enrich.py
```

Перед регулярным обходом прочитайте ограничения источников в плане: у СППИ есть требование разрешения на копирование. Скрипты являются PoC, не промышленным crawler. Повторный запуск перезаписывает часть результатов; исходные снимки текущего эксперимента находятся в poc/.
